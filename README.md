# mall-2

`backend` 폴더를 7z 분할 압축(90MB × 11개)으로 올려 둔 저장소입니다.

## 사용 방법

1. `backend.7z.001` ~ `backend.7z.011` 파일을 **모두** 같은 폴더에 받습니다.
   (Code → Download ZIP 또는 `git clone https://github.com/jinavely/mall-2.git`)
2. `backend.7z.001` 하나만 반디집/7-Zip으로 압축 풀기 하면 나머지가 자동으로 합쳐집니다.
   - 반디집 CLI: `bz x backend.7z.001`
   - 7-Zip: `7z x backend.7z.001`
3. 압축을 풀면 `backend` 폴더가 생성됩니다.
